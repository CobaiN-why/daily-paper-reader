## 摘要
基于AI的工具在软件开发中的使用正在迅速改变软件的生成方式，使得在有限的人工实现投入下能够生成大量代码。然而，这也对确保所生成产物与开发者意图一致并已得到适当验证提出了根本性挑战。在本工作中，我们提出使用结构化论证来驱动AI辅助软件开发。受安全关键系统保障工程技术的启发，我们定义了一种论证理由语言，以结构化且可验证的格式显式关联非形式化自然语言提示、形式化规范、关于开发者意图的假设以及程序分析证据。随后，我们描述了AssureCode，一种工具支持的方法论，用于在智能体代码生成过程中创建此类理由。我们对我们实现进行了实证分析，在其中考察其促进对AI生成代码正确性进行有依据保障的能力。

## Abstract
The use of AI-based tools in software development is rapidly changing how software is produced, enabling large volumes of code to be generated with limited human implementation effort. However, this raises fundamental challenges for ensuring that generated artifacts are aligned with developer intent and have been appropriately validated. In this work, we propose the use of structured argumentation in driving AI-assisted software development. Inspired by techniques from assurance engineering for safety-critical systems, we define a language of justification rationales that explicitly relate informal natural language prompts, formal specifications, assumptions about developer intentions, and program analysis evidence in a structured and verifiable format. We then describe AssureCode, a tool-supported methodology for creating such rationales as part of agentic code generation. We provide an empirical analysis of our implementation where we investigate its capacity to contribute towards justified assurance of correctness for AI-generated code.
