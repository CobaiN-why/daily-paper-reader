## 摘要
可编程逻辑控制器（PLC）编程仍是一项以IDE为中心的手动任务，需要在文档、项目文件和代码编辑器之间不断切换上下文。近期研究表明，检索增强大语言模型能够以较高的编译通过率生成符合厂商规范的结构化文本，但这些系统将代码生成视为一次性流水线：工程师提交查询并获得代码，而对具体工厂没有持久化知识。我们提出一种工厂感知的对话式副驾驶，从三个方向扩展了这一范式：工厂特定上下文的摄入、面向解释与调试的对话优先交互模式，以及从对话到部署的分级工具访问阶梯。该系统面向真实工厂基础设施设计，并确保工程师掌控每个会产生现实影响的步骤。

## Abstract
Programmable Logic Controller (PLC) coding remains a manual, IDE-centric task that demands constant context switching between documentation, project files, and code editors. Recent work has demonstrated that retrieval-augmented large language models can generate vendor-compliant Structured Text at high compilation rates, yet these systems treat code generation as a one-shot pipeline: the engineer submits a query and receives code, with no persistent knowledge of the specific plant. We present a plant-aware conversational copilot that extends this paradigm in three directions: plant-specific context ingestion, a chat-first interaction model for explanation and debugging, and a graduated tool-access ladder from chat to deployment. The system is designed for real plant infrastructure and keeps the engineer in control of each step that produces real-world effects.
