## 摘要
在指令或用户提示模糊的情况下，编码智能体必须决定是提出澄清问题，还是直接尝试求解。虽然向用户澄清可能提升智能体解答的正确性，但每一次来回交互都会带来用户与系统成本，从而形成明确的准确率与效率之间的权衡。现有研究考察了澄清行为，但并未在可强制执行的澄清预算下训练策略；基于惩罚的方法通常需要针对所有澄清预算水平分别调参并逐一扫描系数。我们将澄清建模为约束马尔可夫决策过程（CMDP），并使用PPO-拉格朗日对Qwen2.5-Coder-7B-Instruct进行后训练，以在期望提问预算约束下优化编码准确率。在HumanEvalComm上以GPT-4o-mini作为预言机模拟器进行评估，所得策略表明：未经调优的澄清行为在帕累托意义上是低效的——受预算约束的策略可以同时实现比基线模型更高的准确率和更低的澄清率。在不同预算水平上，我们观察到呈对数形状的帕累托前沿，额外澄清带来的收益递减。这些增益并非仅仅来自总体上提出更多问题，而是来自更优的问题定位以及在模糊情境下更好的代码生成。在没有显式监督的情况下，训练后的策略学会了非均匀地分配澄清预算，在更难（多重退化）的任务上更频繁地提问。这些结果表明，无约束的交互式大语言模型系统可能系统性地低效使用澄清。

## Abstract
Coding agents operating under ambiguous instructions or user prompts must decide whether to ask clarifying questions or attempt a solution directly. While clarification from the user may improve the correctness of the agent's solution, each back-and-forth interaction incurs user and system costs, forming an explicit accuracy vs. efficiency tradeoff. Existing works study clarification behavior but do not train policies under enforceable clarification budgets; penalty-based approaches typically require separate coefficient tuning swept across all clarification budget levels. We formulate clarification as a Constrained Markov Decision Process (CMDP) and post-train Qwen2.5-Coder-7B-Instruct with PPO-Lagrangian to optimize coding accuracy, subject to an expected question-budget constraint. Evaluated on HumanEvalComm with a GPT-4o-mini oracle simulator, the resulting policies reveal that untuned clarification behavior is Pareto-inefficient: budget-constrained policies can simultaneously achieve higher accuracy and lower clarification rates than the baseline model. Across budget levels, we observe a log-shaped Pareto frontier with diminishing returns to additional clarification. Gains arise not from simply asking more questions overall, but from improved question targeting and better code generation under ambiguity. Without explicit supervision, trained policies learn to allocate clarification budget non-uniformly, asking more frequently on tougher (multi-degradation) tasks. These results suggest that unconstrained interactive LLM systems may systematically use clarification inefficiently.

## 1. 核心问题与整体含义

- **研究动机**：编程智能体面对模糊、不完整或自相矛盾的任务说明时，必须在每一轮决定"提出澄清问题"还是"直接提交代码"。追问可提升正确性，但每次往返交互都会消耗用户注意力与系统资源，构成显式的**准确率 vs. 效率权衡**。
- **现有空白**：已有澄清行为研究（Rao & Daumé III 2018；Wu & Fard 2025 等）并未在**可强制执行的澄清预算**下训练策略；基于惩罚（penalty）的方法通常需要针对每个预算水平分别调参并逐一扫描系数，无法在单次训练中适配任意预算。
- **整体含义**：论文将"何时问、问什么"的 ask-vs-answer 路由决策建模为受约束优化问题，证明**未调优的 LLM 澄清行为在帕累托意义上是低效的**——存在既能提高准确率、又能降低提问率的操作点。这暗示无约束的交互式 LLM 系统可能系统性地低效使用澄清。

## 2. 方法论

- **核心思想**：将多轮澄清任务建模为**约束马尔可夫决策过程（CMDP）**，在期望提问预算约束下最大化编码准确率，用 **PPO-Lagrangian** 的后训练端到端优化"路由决策 + 提问内容"。
- **CMDP 形式化**：
  - 状态 $s_t$ = 退化规格 $x$ + 历史问答对；
  - 动作 $a_t \in \{[ASK]\ q_t,\ [ANSWER]\ c_t\}$，即提问或提交 Python 代码；
  - 主成本 $C_q$：一个 `[ASK]` 轮中**不同原子问题数**（防止把多个请求打包进一次提问来钻预算空子），`[ANSWER]` 时为 0；
  - 次成本 $C_t = 1$（每轮一次），软轮次预算 $d_2=4$，硬上限 $T_{max}=6$；
  - 目标：$\pi^*=\arg\max_\pi \mathbb{E}_\pi[R]$，s.t. $\mathbb{E}_\pi[C_i]\le d_i$，$R$ 为 pass@1（通过单元测试比例）。
- **优化流程**：
  - 策略为 Qwen2.5-Coder-7B-Instruct + **LoRA**（$r=16,\alpha=32$，约 40M 可训练参数）；三个价值头分别估计奖励、问题成本、轮次成本的期望回报。
  - 三条 **GAE 流**（$R, C_q, C_t$）各自白化后组合成拉格朗日优势：$A^{lag}_t=\tilde A^R_t-\lambda_1\tilde A^{C_q}_t-\lambda_2\tilde A^{C_t}_t$。
  - 对 continuation token 施加 **clipped PPO 目标**（$\varepsilon=0.2$），**前缀 `[ASK]/[ANSWER]` token 被排除在似然比之外**；路由通过共享 LoRA 参数间接被 shaping。
  - **对偶上升**更新乘子：$\lambda_1\leftarrow \text{clip}(\lambda_1+\eta_{\lambda_1}(\bar q-d_1),0,\lambda_{1,max})$，$\lambda_2$ 同理（$\eta_{\lambda_1}=0.1,\eta_{\lambda_2}=0.005$）。
  - 路由采用**前缀对数概率打分**（比较 `[ASK]` 与 `[ANSWER]` 的区分 token 得分），训练时以温度 0.8 采样，评估时贪心。
  - 完整损失含 PPO 项、KL 正则（$\beta_{KL}=0.25$）、熵奖励（$\beta_H=0.01$）与价值 MSE。

## 3. 实验设计

- **数据集 / Benchmark**：**HumanEvalComm**（HumanEval 的多轮扩展），每个问题规格在呈现前被人工退化，共 772 个退化实例；按 base problem 划分以避免信息泄漏：**303 训练 / 52 验证 / 417 留出测试**。
- **退化类型（7 种）**：`1a,1c,1p,2ac,2ap,2cp,3acp`（数字前缀 = 同时退化数量，后缀 a=歧义、c=矛盾/不一致、p=部分截断）。
- **交互协议**：`[ASK]` 交由 **GPT-4o-mini 预言机模拟器**（温度 0，持真值规格）回答并附原子问题计数；`[ANSWER]` 在隐藏测试上执行并终止。
- **对比对象**：
  - **基线**：冻结的未训练 Qwen2.5-Coder-7B-Instruct（pass@1 = 0.690，$\bar q=0.856$）；
  - **不同预算策略**：$d_1\in\{0,0.25,0.5,0.75,1.0,1.5,2.0\}$，共 10 个策略，其中 $d_1\in\{0.5,0.75,1.0\}$ 各训练两个独立种子；
  - **高预算运行**（$d_1\in\{1.5,2.0\}$，$\lambda_1\approx0$）作为近似的**无约束 PPO 对照**。
- **评估指标**：pass@1（通过断言比例）、每回合平均提问数 $\bar q$、按退化复杂度和问题数分层的 pass@1；统计检验用配对 t 检验与单样本 t 检验（预算合规性）。

## 4. 资源与算力

- 明确给出：训练使用 **2×A100-40GB**，每个预算 **80 次 PPO-Lagrangian 迭代**，**约 11 小时**；每迭代 32 个回合、mini-batch 8、最多 4 个 PPO epoch。
- 优化器为 8-bit AdamW，策略 LR $5\times10^{-6}$（20 步线性 warmup），价值头 LR $10^{-4}$；LoRA 训练约 40M 参数。
- 作者自述受**显著算力约束**，小批量与少迭代是训练不稳定与运行间方差的可能原因。

## 5. 实验数量与充分性

- **实验规模**：7 个预算水平共 10 个训练策略；3 个预算水平（0.5/0.75/1.0）做双种子重复以度量方差；按退化复杂度（1-deg vs. 2/3-deg）与按 7 种退化类型 × 问题数（0Q/1Q/2+Q）做了细粒度拆解；含代表性回合案例分析（附录 D）与训练曲线（附录 B）。
- **客观性与公平性**：
  - 所有策略使用相同超参，仅 $d_1$ 不同；训练/验证/测试按 base problem 划分，防止退化变体泄漏；对照基线在同一多轮条件下评估。
  - 预算合规在测试集上事后检验（如 $d_1=0.75$ 两run均统计合规；$d_1=1.0$ run2 超出预算 $p=0.027$，$d_1=0.25$ 在测试时违规被排除出前沿），做法较诚实。
- **不充分之处**：
  - 训练集仅 303 个实例、来自 64 个 base problem，**小于测试集**；单一 benchmark、单一模型规模。
  - 小批量/少迭代导致运行间方差较大，单次运行结论可靠性受限；离散预算（7 点）之间的真实前沿形状未验证。
  - 缺乏"冻结代码生成头只训提问策略"之类的**消融实验**，难以干净分离问题质量与代码质量的贡献。

## 6. 主要结论与发现

- **帕累托低效性**：受约束策略可**同时**取得比基线更高的 pass@1 与更低的提问率，说明未调优澄清行为处于帕累托低效点。
- **对数形帕累托前沿**：边际准确率增益随提问预算增大而递减，超过某阈值后摩擦成本超过边际收益。
- **最优操作点**：$d_1=0.75$ 是唯一帕累托占优基线的策略（pass@1 提升 +5.8%~+7.1%，$p<0.01$；$\bar q\in\{0.719,0.782\}$ vs. 0.856，$p<0.01$）。$d_1=0.5$ 以约一半提问率保持与基线相当的准确率（$p\ge0.10$）。
- **收益来源是"质量"而非"数量"**：控制问题数（1Q→1Q）后 $d_1=0.75$ 仍 +7.1%（$p<0.001$），表明增益来自更好的问题定位与歧义下更强的代码生成能力。
- **无监督下的非均匀预算分配**：策略自发在更难的**多重退化任务**上提问更多，在整体上提问更少（图 2、图 6）。
- **约束行为**：$d_1\le0.75$ 时 $\lambda_1$ 持续为正并生效；$d_1=1.0$ 时 $\lambda_1$ 间歇激活不持续绑定；$d_1>1.0$ 时 $\lambda_1\approx0$（预算松弛）。$\lambda_2$ 全程为 0（最大批量平均轮次 3.33 < $d_2=4$），故策略行为上为"仅提问"型。
- **过度压制澄清有害**：$d_1\in\{0,0.25\}$ 的策略低于基线。

## 7. 优点

- **问题建模的适配性**：CMDP 形式化天然支持**单次训练覆盖任意预算**，避免惩罚法需按预算逐点调参的成本，是相较既有工作的关键优势。
- **端到端优化路由**：同一策略同时产生"是否提问"的路由决策与提问内容，而非把问题内容固定。
- **防钻空子设计**：以**原子问题计数**而非轮次计费，防止把多个请求打包成一次 `[ASK]` 来规避预算。
- **干净的归因尝试**：通过控制问题数（1Q→1Q）区分"数量 vs. 质量"；以高预算松弛运行作为无约束 PPO 对照。
- **诚实透明的报告**：明确披露运行间方差、预算违规运行（$d_1=0.25$、$d_1=1.0$ run2）、小样本单元格（如 3acp）需谨慎解读。
- **可复现性**：公开实现与训练 checkpoint。

## 8. 不足与局限

- **运行间方差大**：同预算不同种子结果差异明显（如 $d_1=0.5$ 时 0.683 vs. 0.719），单次运行结论可靠性受限。
- **训练规模与稳定性**：仅 80 迭代、rollout 32、mini-batch 8，梯度方差大，影响对偶上升的稳定性。
- **模拟器保真度**：GPT-4o-mini 温度 0 的确定性回答消除了答案噪声，但无法反映真实人类回答的改写、含糊或主动补充信息等变异性。
- **基准单一且训练集小**：仅 HumanEvalComm 与人工合成退化类型，303 训练实例（来自 64 个 base problem）小于 417 测试集，泛化性未验证。
- **规模受限**：仅 7B 模型 + LoRA，能否扩展到更大模型、预算分配行为与乘子动态是否稳定未知。
- **离散预算覆盖**：仅 7 个预算点，前沿形状由对数拟合插值，区间内真实最优曲线未验证。
- **归因不清**：PPO 联合优化提问与代码生成，难以将增益完全归因于澄清行为改善；缺少受控消融。
- **应用限制**：预算在训练时经拉格朗日乘子施加，评估时策略自由生成、预算合规仅事后检验，部署时若无外部约束可能偏离目标预算；作者建议未来引入随问题复杂度自适应的**动态预算**，并在真实人类预言机、自然歧义场景与更大规模上验证。
