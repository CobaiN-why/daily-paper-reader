## 摘要
代码大语言模型从大规模代码语料中习得编程能力，但也可能记住一些后续需要移除的实现。当出现版权或安全担忧时，需要代码遗忘来控制其继续复现。然而，目标代码与保留代码共享计算模式，在遗忘特定实现与保持通用编程能力之间形成张力。我们提出 UNBIND，一个代码遗忘框架，分别考虑哪些隐藏状态对应于目标代码以及如何抑制其复现。通过为这些目标构建不同的方向，UNBIND 在推理时实现选择性遗忘，同时保持模型权重固定。我们的评估涵盖两个代码模型和两个语料上的十四个基线。UNBIND 在每种设置中都取得了最高的遗忘与效用联合得分。以 F-BLEU 衡量，它将目标代码复现降低了 97.3% 到 99.1%，相比原始模型最多少解决两个 HumanEval+ 和六个 MBPP+ 问题。在固定预算下的重复提取测试中，每个设置中产生至少 50 个 token 的精确片段的目标数量从 188--262 降至 300 个中的 0--2 个。没有提取出的片段达到 100 个 token，平均最佳恢复率范围为 0.43% 到 6.45%。多语言及相关代码评估进一步表明，其能有效遗忘，同时对有用编程能力的影响有限，支持 UNBIND 作为一种实用的选择性代码遗忘方法。

## Abstract
Code large language models acquire programming capabilities from large code corpora, but can also memorize implementations that later require removal. Code unlearning is needed to control their continued reproduction when copyright or security concerns arise. However, targeted and retained code share computational patterns, creating a tension between forgetting specific implementations and preserving general programming ability. We propose \textbf{UNBIND}, a code unlearning framework that separately considers which hidden states correspond to the target code and how to suppress its reproduction. By constructing separate directions for these objectives, UNBIND achieves selective unlearning at inference time while keeping model weights fixed. Our evaluation covers fourteen baselines across two code models and two corpora. UNBIND achieves the highest joint forgetting and utility score in every setting. It reduces target code reproduction by 97.3\% to 99.1\% as measured by F-BLEU, with at most two fewer HumanEval+ and six fewer MBPP+ problems solved than the original models. In repeated extraction tests under a fixed budget, the number of targets yielding exact spans of at least 50 tokens falls from 188--262 to 0--2 out of 300 per setting. No extracted span reaches 100 tokens, and the mean best recovery ratio ranges from 0.43\% to 6.45\%. Multilingual and related-code evaluations further show effective forgetting with limited impact on useful programming capabilities, supporting UNBIND as a practical approach to selective code unlearning.
