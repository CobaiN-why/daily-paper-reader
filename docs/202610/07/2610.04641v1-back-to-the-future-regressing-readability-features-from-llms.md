## 摘要
代码可读性支持软件理解、审查和维护。随着 AI 编码智能体越来越广泛地使用，可读代码既有助于人类审查智能体生成的输出，也有助于智能体在有限上下文窗口内维护代码。然而，现有可读性模型在不同数据集上并不总能与人类判断一致。我们提出 BTTF（Back To The Future），将线性回归与信息论特征相结合。BTTF 不将语言模型用作黑盒评判者，而是将其用作测量工具。它结合传统代码度量、基于嵌入的语义组织以及因果 LM 可预测性，以捕捉源代码结构、语义连贯性和上下文惊奇度。我们在五个公开的、有人工评分的可读性基准以及我们人工标注的 MBJP 开发集上评估 BTTF，总计 1,100 个样本。BTTF 将平均 Spearman 相关系数较最强基线提升最多 0.101。在生产代码上的 13 种受控的降低可读性的变换中，它在 Java 和 Python 中分别达到 93.8% 和 87.6% 的响应率，比 Dorn 分别高出 14% 和 19.2%。它在本地模型中表现最佳，在 Java 和 Python 中分别落后于最强的云端 LLM 响应 1.7% 和 5.1%。直接使用 LLM 的基线每次评估平均需要 1,083 个提示 token，同时仍是不透明的。BTTF 将最先进的基准性能、强大的变换鲁棒性与特征粒度的可解释性结合起来：在所有评估的模型配置中，每个特征系数都与其理论方向效应一致。

## Abstract
Code readability supports software understanding, review, and maintenance. As AI coding agents become more widely used, readable code helps both humans review agent-generated output and agents maintain code within limited context windows. Yet existing readability models do not consistently agree with human judgements across datasets.   We introduce BTTF (Back To The Future), pairing linear regression with information-theoretic features. Rather than using language models as black-box judges, BTTF uses them as measurement instruments. It combines traditional code measurements, embedding-based semantic organisation, and causal-LM predictability to capture source structure, semantic coherence, and contextual surprise.   We evaluate BTTF on five publicly available human-rated readability benchmarks and our manually annotated MBJP development set, totalling 1,100 samples. BTTF improves average Spearman correlation over the strongest baseline by up to 0.101. Across 13 controlled readability-reducing transformations on production code, it achieves response rates of 93.8% in Java and 87.6% in Python, outperforming Dorn by 14% and 19.2%. It performs best among local models and trails the strongest cloud-LLM response by 1.7% in Java and 5.1% in Python. The direct-LLM baselines require an average of 1,083 prompt tokens per evaluation while remaining opaque. BTTF combines state-of-the-art benchmark performance and strong transformation robustness with feature-granular interpretability: every feature coefficient matches its theoretical directional effect across all evaluated model configurations.
