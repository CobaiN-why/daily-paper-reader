## 摘要
基于大语言模型（LLM）的智能体正越来越多地用于软件工程任务，但其性能并非仅由基础模型决定。智能体 Harness 在很大程度上决定了软件工程智能体如何与代码仓库交互、执行动作并验证解决方案。然而，人们对 Harness 设计的作用仍认识不足，尤其是在不同模型、任务和 Harness 组件之间。本文对软件工程智能体中的 Harness 效应进行了系统的实证研究。我们首先在两个主要开放权重模型系列 Qwen 和 DeepSeek 的十个模型上，使用 SWE-bench Pro、ProgramBench 和 GitTaskBench 三个基准，评估了两种代表性 Harness：mini-SWE-agent 和 OpenCode。随后，我们构建了 NanoHarness，一个基于 mini-SWE-agent 的轻量级模块化 Harness，并用它分析五个代表性 Harness 组件：工具注册表、上下文压缩、显式规划、子智能体和惰性技能。实验结果表明，Harness 的有效性共同取决于模型能力和任务类型。随着模型能力提升，复杂 Harness 在 SWE 风格问题修复上的边际收益递减，但在更复杂、开放式的仓库级任务上可使更强的模型受益。在 ProgramBench 上的组件级分析进一步表明，结构化工具使用和任务特定子智能体提供了最稳定的改进，而上下文压缩和通用子智能体可能损害仓库生成性能。组合使用时，NanoHarness 在 Qwen3.7-Max 和 DeepSeek-V4-Pro 上分别比 mini-SWE-agent 提升 7.37 和 6.21 个百分点，恢复了产品级 Harness 的大部分收益。这些发现凸显了 Harness 设计是软件工程智能体性能的一等要素，并为构建更有效、更高效的编码智能体提供了洞见。

## Abstract
Large Language Model (LLM)-based agents are increasingly used for software engineering tasks, yet their performance is not determined by the base model alone. The agent harness substantially shapes how SE agents interact with repositories, execute actions, and validate solutions. However, the role of harness design remains insufficiently understood, especially across different models, tasks, and harness components. In this paper, we present a systematic empirical study of harness effects in SE agents. We first evaluate two representative harnesses, mini-SWE-agent and OpenCode, with ten models from two prominent open-weight model families, Qwen and DeepSeek, on three benchmarks: SWE-bench Pro, ProgramBench, and GitTaskBench. We then construct NanoHarness, a lightweight modular harness built on top of mini-SWE-agent, and use it to analyze five representative harness components: tool registry, context compression, explicit planning, subagents, and lazy skills. Experimental results show that harness effectiveness depends jointly on model capability and task type. Complex harnesses provide diminishing marginal gains on SWE-style issue repair as model capability improves, but can benefit stronger models on more complex and open-ended repository-level tasks. Component-level analysis on ProgramBench further shows that structured tool use and task-specific subagents provide the most stable improvements, while context compression and general subagents can hurt repository-generation performance. When combined, NanoHarness improves over mini-SWE-agent by 7.37 and 6.21 percentage points on Qwen3.7-Max and DeepSeek-V4-Pro, respectively, recovering most of the gains of product-level harnesses. These findings highlight harness design as a first-class factor in SE-agent performance and provide insights for building more effective and efficient coding agents.

- **研究动机**：LLM 软件工程智能体的性能不仅取决于基座模型，还取决于模型外部的“agent harness”，即围绕模型的上下文检索、工具调用、执行环境、补丁生成与验证等基础设施。

## 2. 方法论

### 2.1 总体研究框架

论文设计了两部分互补研究：

- **Study 1：模型–Harness–任务联合效应**  
  在三个 SE 基准上，用两个代表性 harness 评测来自 Qwen 和 DeepSeek 的十个模型，形成三维实验矩阵。
- **Study 2：组件级 Harness 分析**  
  基于 mini-SWE-agent 构建轻量模块化 harness **NanoHarness**，逐个启用/禁用五类代表性组件，分析单独效应与组合效应。

### 2.2 NanoHarness 的五类核心组件

- **工具注册表（Tool Registry）**  
  将 mini-SWE-agent 的 Bash 交互扩展为统一工具层，引入 `read_file`、`write_file`、`edit_file`、`glob` 四个文件系统工具，支持有界文件检查、创建/覆盖、局部编辑和模式化文件发现。
- **上下文压缩（Context Compression）**  
  面向长程执行：超大工具输出持久化到工作区，仅保留路径和短预览；历史过长时进行消息裁剪和观察压缩，保留近期结果和高价值输出；仍超限时触发 LLM 摘要。支持手动压缩和上下文窗口错误后压缩，预算为 350K token，压缩时保留最近 20 条消息。
- **显式规划（Explicit Planning）**  
  加入 TodoWrite 风格轻量规划：智能体调用 `todo_write` 维护短任务列表，最多一个条目为 `in_progress`；由 TodoManager 校验格式、状态、长度和一致性；当前计划渲染回提示词并保存至轨迹元数据；若多轮未更新则注入提醒。
- **子智能体（Subagents）**  
  父智能体保留任务控制、预算管理和最终提交，子智能体在共享工作区中以全新历史运行，使用受限工具白名单，通过 `finish_subagent` 返回结构化报告；禁用嵌套委派，最多 50 轮。
  - **通用 SE 子智能体**：按生命周期分为需求分析、架构设计、代码生成、测试生成、缺陷修复。
  - **任务特定子智能体**：行为分析、差分测试、提交审查。
- **惰性技能（Lazy Skills）**  
  将过程性知识作为按需加载资源：提示词中仅含紧凑技能目录，智能体调用 `load_skill(name)` 获取详细指导。技能包括终端工作流、最小实现、构建诊断、测试分诊、CLI 模糊测试、提交审查等。

### 2.3 算法/流程说明

- 从 mini-SWE-agent 这一最小 harness 出发，以“积木式”方式增量加入五类组件，形成多个受控变体。
- 在统一执行协议下评测每个变体，并与 OpenCode、Claude Code 等产品级 harness 对比。
- 除性能外，还收集步数、工具调用、prompt/response token 等行为统计，并进行轨迹级失败模式分析。

## 3. 实验设计

  - **GitTaskBench**：仓库中心真实任务求解，Python，共 54 实例。
- **Harness 对比**：
  - **mini-SWE-agent**：轻量级、基础命令行交互 harness。
