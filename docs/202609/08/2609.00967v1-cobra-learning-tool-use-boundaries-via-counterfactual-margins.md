## 摘要
随着大型语言模型越来越多地通过外部工具行动，决定何时调用工具已成为与决定如何使用工具并列的核心问题。不必要的工具调用会引入延迟、成本、检索噪声和错误传播，而遗漏调用则会损害知识密集型查询或需要最新证据的问题。现有方法通常根据绝对查询或生成信号（如难度、置信度或最终任务奖励）来触发工具，因此缺乏对工具使用实例级边际收益的明确估计。我们提出CoBRA，一种用于工具增强语言模型的反事实边界学习框架。CoBRA首先从同一基座模型构建内部和外部专家，收集配对轨迹，并估计有工具与无工具回答之间的奖励边际。该边际将数据划分为内部偏好、外部偏好和模糊案例。然后，CoBRA使用清晰边际样本进行边界感知冷启动SFT，随后进行带参考分裂轨迹和反事实边际优势的MARS-RL，以优化边界决策。以Qwen3-4B上的检索为主要工具的实验表明，CoBRA提高了工具使用效率和边界敏感的回答准确性，同时在依赖工具的外分布问题上保持了强劲性能。

## Abstract
As large language models increasingly act through external tools, deciding when to call a tool has become a central problem alongside deciding how to use it. Unnecessary tool calls introduce latency, cost, retrieval noise, and error propagation, while missed calls hurt knowledge-intensive queries or questions requiring up-to-date evidence. Existing methods typically trigger tools from absolute query or generation signals, such as difficulty, confidence, or final task reward, and therefore lack an explicit estimate of the instance-level marginal benefit of tool use. We propose CoBRA, a counterfactual boundary-learning framework for tool-augmented language models. CoBRA first constructs internal and external experts from the same base model, collects paired trajectories, and estimates the reward margin between answering with and without tools. This margin partitions data into internal-favored, external-favored, and ambiguous cases. CoBRA then uses clear-margin samples for Boundary-Aware Cold-Start SFT, followed by MARS-RL with reference-split rollouts and counterfactual marginal advantages to optimize boundary decisions. Experiments with retrieval as the main tool on Qwen3-4B show that CoBRA improves tool-use efficiency and boundary-sensitive answer accuracy while maintaining strong performance on tool-dependent out-of-distribution questions.

### 1. 核心问题与整体含义（研究动机与背景）

- **核心问题**：大语言模型（LLM）作为代理调用外部工具时，**"是否调用工具"的时机决策**（工具路由问题）至关重要。这并非简单的能力二元判断——不必要的调用增加延迟、成本、检索噪声与错误传播；漏调用则损害知识密集型或需实时证据的问题。
- **现有方法的不足**：既有条件检索或自适应检索方法，多依赖**绝对信号**（如不确定性、置信度、问题复杂度、自我反思或最终任务奖励）来触发工具调用，**缺乏对"工具使用的实例级边际收益"的显式估计**。一个难题不等于一个能从工具中受益的问题；一个自信的模型在过时或长尾事实上仍可能出错。
- **关键实证支撑**：论文通过同一基座模型派生出"内部专家"和"外部专家"执行配对 rollout，发现不同基准的反事实边际类别构成差异悬殊（例如 TriviaQA 更多外部偏好，2WikiMultiHop 强烈内部偏好），说明**粗粒度的数据集身份无法解释工具使用的实例级收益**，工具路由应建模为实例级反事实决策。

### 2. 方法论：核心思想、关键技术细节与公式（文字描述）

**整体框架**为 CoBRA，包含两大模块：**反事实边界发现** 与 **边界感知策略优化**，训练奖励函数定义为：
- $R(\tau) = S(\tau) - \lambda C(\tau)$：任务正确性评分减去工具成本（$\lambda$ 控制准确率-成本平衡）。

**模块一：反事实边界发现（Counterfactual Boundary Discovery）**
- **双专家构建**：从同一基座模型，通过拒绝采样微调构建：
  - 内部专家 $M_{int}$：无工具回答（捕获参数化知识能力）；
  - 外部专家 $M_{ext}$：强制调用工具并整合返回证据。
- **边际估计**：同一查询上，评估两分支轨迹效用之差：$\hat{\Delta}(q) = R(\tau_{ext}|q) - R(\tau_{int}|q)$（多 rollout 时取分支平均）。采用大规模确定性单 rollout + 大样本量降方差。
- **数据划分**：以阈值 $\epsilon$ 将数据分为三组：$D_{int}$（内部偏好）、$D_{ext}$（外部偏好）、$D_{amb}$（模糊集）。**双错样本归入模糊集**，避免把"工具成本导致的更差效用"误判为"内部更优"。

**模块二：边界感知策略优化（Boundary-Aware Policy Optimization）**
- **边界感知冷启动 SFT**：仅用清晰偏好数据 $D_{int} \cup D_{ext}$ 训练，全部使用相同系统提示词与工具 schema（模型自主学习是否调用工具，而非强制分支），排除模糊集避免噪声标签，输出热身模型 $M_{warm}$。
- **MARS-RL**（Marginal Advantage from Reference-Split Rollouts，参考分裂 rollout 的边际优势）：
  - **参考分裂 rollout**：对同一查询强制从内部（抑制工具）和外部（工具调用前缀）两分支采样，共享系统提示与参考策略，确保奖励差反映工具价值而非格式差异。
  - **分支内归一化优势 (PBN)**：在各分支内独立作组内相对优势，避免高分分支压制另一分支内优质样本。
  - **在线分支边际 (BM)**：计算两分支组平均效用差并归一化：$\tilde{\Delta}_B(q) = \Delta_B(q)/(\sigma_B+\eta)$。
  - **MARS 优势**：$A^{MARS}_i = A^{within}_i + \beta \cdot \text{sign}(T_i) \cdot \tilde{\Delta}_B(q)$（外部轨迹取正、内部轨迹取负），对称注入分支层面路由信号。
  - 以 PPO 风格截断目标优化（含 KL 正则）。

### 6. 主要结论与发现

- **固定检索派不上用场**：与纯内部模型相比，外部专家 $M_{ext}$ 在 ID 上提升 jEM 19.15pp、OOD 27.88pp，确认工具价值需正确路由方能兑现。
- **热身模型 $M_{warm}$ 已能改善效率-质量权衡**：相较 $M_{ext}$，ID 工具调用减少 47.0%，效用从 0.3544 提升到 0.4148。
- **MARS-RL 带来显著增益**：相较 $M_{warm}$，CoBRA 将 ID jEM 提升 9.15pp、OOD 9.04pp；在 5 主基准中 4 个上 jEM 最高；对比 Search-R1-3B，ID/OOD 效用分别 +0.0759/+0.0866，工具调用减少 20.1%/22.2%。
- **边界行为更健康**：模糊子集 $D_{amb}$ 上 jEM 达 0.9658（超越 Search-R1-3B 6.14pp，超越 $M_{warm}$ 3.66pp），且调用次数更少；过调用率与欠调用率均保持低水平——收益并非来自无差别检索。

### 7. 优点

- **问题定义精确**：将工具路由显式定义为"实例级边际效用最大化"的反事实决策，概念清晰，优于绝对信号启发式。
- **方法论设计严谨**：
  - 双专家同源构建确保公平对比；训练全程使用**统一提示与工具 schema**，避免格式混杂误导学习；
  - 数据三分法（内部偏好/外部偏好/模糊）合理，将模糊样本推迟至 RL 阶段非硬标签处理；
  - MARS-RL 的 PBN+BM 设计精巧，避免常规 GRPO 中"分支间掩盖分支内质量"的问题，并将分支路由信号显式注入优势函数，破解纯结果奖励对工具价值不敏感的根本困境。
- **评测系统完备**：jEM 引入判官评测并验证与人工一致性；提供 EM/F1/cost/Pareto 多维度画像；消融设计（组件 + 冷启动）支撑结论。
- **落地验证加分**：音乐域（工业规模）实验说明框架具有垂直领域可迁移性与实用价值。

### 8. 不足与局限

- **验证范围偏窄**：仅验证单一种基座模型（Qwen3-4B）与单一工具类型（Wikipedia 检索引擎），多工具、多模型家族、多智能体环境下的通用性未验证。
- **关键超参依赖**：反事实边际依赖 rollout 质量、评分器可靠性、检索行为、λ（成本系数）与 ϵ（划分阈值）选择，敏感性分析仅覆盖 λ，ϵ 等未充分讨论。
- **成本建模过于简化**：仅以"调用次数"衡量工具成本，真实部署中延迟、API 价格、隐私、安全、用户体验等成本维度未被纳入；工具成本不随次数线性增长时（如缓存命中）该建模失效。
- **配对 rollout 方法局限**：S2 阶段采用每分支一次的确定性 rollout，依赖样本规模而非重复采样降方差，对高方差查询的边际估计可能不稳定。
- **潜在偏差风险**：双错样本"均匀"并入模糊集，但各数据集中模糊集占比较高，其对 RL 训练稳定性的潜在影响未单独隔离分析；OOD 数据集 PopQA 测试集与 Wikipedia 检索时效的交互效应未深入考察。
- **安全边界提示**：论文在伦理声明中承认，路由错误可能传播过期或不实内容，不能视为高风险自主场景下安全工具操作保证。
