## 摘要
仓库级软件工程（SWE）包含异构任务类别，这些类别在池化智能体强化学习下的进展可能不均衡：某些类别的提升伴随着其他类别的退化，而总体解决率掩盖了这些变化。受这种类别跷跷板现象启发，我们开发了一个类别感知的专家训练与策略集成框架。可执行任务构建与 SWE Labeler（一种基于证据的多轴标注系统）组织训练池。初始的类别特定 RL 提高了平均训练成功率，但实例级进展仍不均衡，这促使我们显式整合成功行为并进行策略自适应任务选择。同源类别专家交替进行长时程 Agentic-miniRL 与 Refresh-Repair-Expand（RRE）：更新后的策略刷新实例掌握情况，复用其自身验证成功的轨迹进行 Repair SFT，并重新选择任务以进一步 RL。标签路由的多教师同策略蒸馏（MOPD）将专家整合为一个可部署的学生模型，并通过 ReLU 门控的奖励外推，仅保留每个教师相对于参考模型的改进方向。专家训练与策略集成不需要外部模型提供解决方案轨迹或动作目标。我们通过总体与各类别解决率、相对于每个联合 RL 基线的最小类别提升以及专家增益恢复，来评估 Pooled RL 与 Balanced RL、专家开发和单模型集成。最终 MOPD 策略在 Pro-618 上达到 58.04% 的平均解决率，在 SWE-bench Multilingual 上达到 59.00%，分别比基础模型提升 5.39 和 2.78 个百分点。

## Abstract
Repository-level software engineering (SWE) comprises heterogeneous task categories, whose progress under pooled agentic reinforcement learning can be uneven: gains in some categories coincide with regressions in others, while aggregate resolution obscures these changes. Motivated by this category see-saw, we develop a category-aware expert-training and policy-integration framework. Executable task construction and SWE Labeler, an evidence-grounded multi-axis labeling system, organize the training pools. Initial category-specific RL improves average training success while leaving uneven instance-level progress, motivating explicit consolidation of successful behavior and policy-adaptive task selection. Same-origin category experts alternate long-horizon Agentic-miniRL with Refresh-Repair-Expand (RRE): the updated policy refreshes instance mastery, reuses its own verified successful trajectories for Repair SFT, and reselects tasks for further RL. Label-routed multi-teacher on-policy distillation (MOPD) consolidates the experts into one deployable student, with ReLU-gated reward extrapolation keeping only each teacher's improving direction over the reference. Expert training and policy integration require no external model to provide solution trajectories or action targets. We evaluate Pooled RL and Balanced RL, expert development, and single-model integration through aggregate and per-category resolution, the minimum category lift over each joint-RL baseline, and expert-gain recovery. The final MOPD policy achieves mean resolution of 58.04% on Pro-618 and 59.00% on SWE-bench Multilingual, improving over the base model by 5.39 and 2.78 percentage points, respectively.

- **整体含义**：论文旨在回答两个问题——（1）平衡类别曝光能否改善共享策略中的协同学习？（2）类别特定训练能否培养更强的专家，并将其增益整合进单一模型？最终目标是产出一个在总体与各类别解决率上均优于联合 RL 基线的单一可部署策略。

## 2. 方法论：核心思想、关键技术细节与算法流程

### 2.1 整体框架（One to More, More to One）

从单一基座模型出发，拆分为多个同源类别专家（One to More），再通过多教师蒸馏合并回单一学生模型（More to One）。框架由四个部件构成：可执行任务构建、SWE Labeler 标注系统、Refresh–Repair–Expand（RRE）专家训练、标签路由多教师同策略蒸馏（MOPD）。**专家训练与策略整合全程不需要外部模型提供解决方案轨迹或动作目标。**

### 2.2 可执行 SWE 任务构建

- 从合并的仓库 PR 与关联 issue 构建任务池，每个实例含基座修订、issue 式问题陈述、环境规范与可执行测试。
- 修复补丁与测试补丁分离；用 LLM 改写 PR/issue 内容为问题陈述；泄漏检查拒绝暴露源码/测试路径或新增补丁代码的陈述；去重与污染审计进一步过滤。
- 环境构建遵循 RepoLaunch，生成含重建与测试命令的 Docker 镜像；通过运行金标补丁前后的测试验证实例，保留 fail-to-pass 与 pass-to-pass 测试；重复金标检查过滤不稳定验证器。
- 最终池约 32K 可执行候选。

### 2.3 SWE Labeler：基于证据的分层标注系统

- **标注空间**：每个实例获得两个语义轴——**Task Type**（维护意图）与 **Repository Domain**（软件生态），以及三个正交尺度轴——修改范围、认知复杂度、预计解决时间。最终分类包含 26 个 Task Type L1 族/119 个 L2 标签、21 个 Repository Domain L1 族/108 个 L2 标签，三个尺度轴各四级共 12 级。
- **分类学依据**：Task Type 轴借鉴 ISO/IEC 25010、ISO/IEC/IEEE 14764、MITRE CWE、Fowler 重构目录；Repository Domain 轴基于主流框架与平台文档；尺度轴结合仓库拓扑、实证 SWE 分析与认知负荷理论。
- **标签契约**：每个细粒度标签是决策记录 $E(\ell) = \langle a_\ell, d^{src}_\ell, d^{op}_\ell, s^+_\ell, b_\ell \rangle$，即权威来源、源概念、操作性 SWE 规则、可观测正向信号、与相邻标签的边界。
- **标注流程**：两阶段分层标注——先预测 L1，再从对应 L1 子节点中选择 L2 并赋予尺度轴；输出对照 L1–L2 层级与合法尺度级校验。
- **路由构造**：完整标注 $z(x)$ 比直接专家路由更丰富，故使用 Repository Domain L1 作为路由轴，将 18 个可路由 Domain L1 族粗化为三个工程语境：A（服务/数据/安全）、B（用户界面应用）、C（系统/工具/运行时），即 $c(x) = g_\psi(z^{domain}_{L1}(x)) \in \{A, B, C, \varnothing\}$。

### 2.4 Agentic-miniRL（长时程智能体 RL）

基于 MiniRL 的策略梯度变体，针对四类优化挑战设计：

- **RLOO 奖励中心化**：可执行验证仅提供稀疏二值终端奖励，混合结果 rollout 组稀缺。采用留一法基线 $\bar{R}_i = R_i - \frac{1}{G-1}\sum_{j\neq i}R_j = \frac{G}{G-1}A^{GRPO}_i$，避免通过自包含基线进一步衰减信号；G=8 时单成功组中成功轨迹得优势 1（含均值中心化为 7/8）。
- **K1 正则置于回报路径**：$d^{K1}_{i,t} = \log \pi_{\theta^-}(a_{i,t}|h_{i,t}) - \log \pi_{ref}(a_{i,t}|h_{i,t})$，$er_{i,t} = \mathbb{1}[t=T_i]\bar{R}_i - \beta d^{K1}_{i,t}$，再做反向折扣累积。K1 作停梯度奖励给出 KL 正则目标的无偏 score-function 梯度，优于直接微分 K3。
- **MiniRL token 更新与近端保护**：用有界重要性权重 $w_{i,t}$ 修正 rollout 行为策略 $\mu_b$ 与训练器 $\pi_{\theta^-}$ 的概率不匹配；符号感知掩码 $M_{i,t}$ 仅在策略沿优势鼓励方向越过边界后抑制更新。
- **轮次感知归约**：轨迹由助手动作轮与工具观测交替构成，损失在助手轮内 token 求和、轮间平均、轨迹间平均（seq-mean-segment-sum），工具观测 token 被响应掩码排除。

### 2.5 Refresh–Repair–Expand（RRE）专家训练

三个类别专家 $c \in \{A,B,C\}$ 均从同一强基座 $\pi_0$ 出发，通过可执行 Agentic RL 直接获得类别行为。每轮含 RL 阶段与 Repair SFT 阶段，各阶段后做掌握度刷新。

- **信号感知初始探索**：复用语料构建时的基座掌握度估计 $\hat{p}(x;\pi)$，RL 选择器优先非极端通过率（重复 rollout 同时暴露成功与失败），仅当实例别处有已验证成功时才纳入少量零通过率实例。
- **Refresh（刷新）**：阶段内选择目标类别分辨率 $S_c$ 最高的模型；RL 后在 RL 训练集上重估，得到配对变化 $\Delta^{(r)}_c(x) = \hat{p}^{(r)}_{c,RL}(x) - \hat{p}^{(r)}_{c,pre}(x)$，揭示"聚合提升不意味着所有已解决实例保持解决"。
- **Repair（修复）**：仅回放前一 RL 阶段中该专家自己生成、经验证器批准的成功轨迹 $B^{(r)}_c(x)$；实例配额 $q^{(r)}_c(x) = g_{rep}(\hat{p}^{(r)}_{c,RL}(x))$ 非增——低掌握度实例获更多不同成功轨迹，已掌握实例获更少。损失 $\mathcal{L}^{(r)}_{c,rep}$ 仅对助手生成 token 计算，是奖励过滤形式的轨迹自蒸馏，而非第二来源的专家演示。
- **Expand（扩展）**：下一 RL 前，将当前 RL 集与随机采样的基座通过率为 0 或 1 的额外实例合并，重估得到下一个 pre-RL 掌握图。下一探索集 $S^{(r+1)}_{c,RL} = F^{(r+1)}_c \cup Z^{(r+1)}_c$，其中 $F$ 是当前信息性前沿 $0 < \hat{p} < 1$，$Z$ 是当前未解决但历史上有成功证据的实例；纯硬零与当前饱和实例被排除。

### 2.6 标签路由多教师同策略蒸馏（MOPD）

- 学生从原始基座 $\pi_0$ 初始化，在三个初始 RL 任务池的类别平衡混合上训练（小池上采样至最大池）。
- 学生生成完整轨迹，教师仅在学生实际访问的前缀上被查询。定义学生–教师差距 $d_{t,k} = q_t - \log\pi_{T_k}(y_t|h_t)$ 与教师–参考差距 $e_{t,k} = \log\pi_{T_k}(y_t|h_t) - \log\pi_{ref}(y_t|h_t)$。
- **路由多教师优势含 ReLU 门控外推项**：$A^{MOPD}_t = \sum_k m_k(x)[-d_{t,k} + (\lambda_k - 1)\max(e_{t,k}, 0)]$。$\lambda_k=1$ 时退化为标准 MOPD 模仿项；$\lambda_k>1$ 时在教师比参考更偏好的 token 上外推。配置用 $\lambda_k = 1.25$，ReLU 门控启用。
- **学生目标**：$L_{MOPD}(\theta) = -\frac{1}{B_{valid}}\sum_i \frac{1}{|S_i|}\sum_{s\in S_i}\sum_{t\in s}\tilde{A}^{MOPD}_t \log\pi_\theta(y_t|h_t)$，$\tilde{A}$ 裁剪至 $[-5,5]$，采用轮次感知的 vanilla 策略梯度，无近端掩码/重要性修正，无环境奖励项、KL 损失或熵奖励。
- **同源教师**：共享 tokenization、prompt 格式、基座 checkpoint 与智能体接口，减少跨专家的无关不匹配。
