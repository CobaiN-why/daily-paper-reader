## 摘要
仓库级软件工程（SWE）包含异构任务类别，在池化智能体强化学习下，其进展可能不均衡：某些类别的提升伴随着其他类别的回退，而总体解决率会掩盖这些变化。受这种类别跷跷板现象启发，我们提出了一个类别感知的专家训练与策略集成框架。可执行任务构建和 SWE Labeler（一个基于证据的多轴标注系统）组织训练池。初始的类别特定 RL 提高了平均训练成功率，但实例级进展仍不均衡，这促使我们显式地巩固成功行为并采用策略自适应任务选择。同源类别专家交替进行长时程 Agentic-miniRL 与 Refresh-Repair-Expand（RRE）：更新后的策略刷新实例掌握情况，复用其自身已验证的成功轨迹进行 Repair SFT，并重新选择任务以进行进一步 RL。标签路由的多教师同策略蒸馏（MOPD）将专家整合为一个可部署的学生模型，并通过 ReLU 门控的奖励外推仅保留每个教师相对于参考模型的改进方向。专家训练和策略集成不需要外部模型提供解决方案轨迹或动作目标。我们通过总体与各类别解决率、相对于每个联合 RL 基线的最小类别提升，以及专家收益恢复，来评估 Pooled RL 和 Balanced RL、专家开发和单模型集成。最终 MOPD 策略在 Pro-618 上达到 58.04% 的平均解决率，在 SWE-bench Multilingual 上达到 59.00%，分别比基础模型提升 5.39 和 2.78 个百分点。

## Abstract
Repository-level software engineering (SWE) comprises heterogeneous task categories, whose progress under pooled agentic reinforcement learning can be uneven: gains in some categories coincide with regressions in others, while aggregate resolution obscures these changes. Motivated by this category see-saw, we develop a category-aware expert-training and policy-integration framework. Executable task construction and SWE Labeler, an evidence-grounded multi-axis labeling system, organize the training pools. Initial category-specific RL improves average training success while leaving uneven instance-level progress, motivating explicit consolidation of successful behavior and policy-adaptive task selection. Same-origin category experts alternate long-horizon Agentic-miniRL with Refresh-Repair-Expand (RRE): the updated policy refreshes instance mastery, reuses its own verified successful trajectories for Repair SFT, and reselects tasks for further RL. Label-routed multi-teacher on-policy distillation (MOPD) consolidates the experts into one deployable student, with ReLU-gated reward extrapolation keeping only each teacher's improving direction over the reference. Expert training and policy integration require no external model to provide solution trajectories or action targets. We evaluate Pooled RL and Balanced RL, expert development, and single-model integration through aggregate and per-category resolution, the minimum category lift over each joint-RL baseline, and expert-gain recovery. The final MOPD policy achieves mean resolution of 58.04% on Pro-618 and 59.00% on SWE-bench Multilingual, improving over the base model by 5.39 and 2.78 percentage points, respectively.

- **核心问题——"类别跷跷板"（category see-saw）**：在池化（Pooled）智能体强化学习下，单一共享策略在不同类别上的进展不均衡，某些类别的提升往往伴随其他类别的回退；而聚合解决率（aggregate resolution）会掩盖这种内部再分配，导致"整体分数稳定但内部结构已变"的假象。
- **现有工作的三类缺口**：
  - **池化混合联合训练**（SWE-RL、SWE-Gym、SWE-Master）：便利但抑制了优化相关的任务结构，联合更新可能顾此失彼，聚合指标无法揭示。
  - **流水线子任务分解**（Agentless、SWE-Fixer、AutoCodeRover）：按功能阶段（定位、修复）分解，与本文按任务类别分解互补但不同。
  - **跨域专家拆分与融合**（Branch-Train-Merge、MOPD、ExOPD）：在数学、代码、指令跟随等传统领域边界上操作，而仓库级 SWE 内部没有现成的领域划分。
- **整体含义**：论文提出将单一 SWE 领域内部按可观测任务标签显式划分为类别，训练类别专家并整合为单一可部署策略，同时以类别级指标替代单一聚合指标，使"跷跷板"可测量、可干预。

## 2. 方法论

### 2.1 核心思想

- **One to More**：从单一基座出发，按类别训练多个同源专家；
- **More to One**：通过标签路由多教师同策略蒸馏（MOPD）将专家整合回单一学生模型；
- 全程**不依赖外部模型提供解轨迹或动作目标**，教师仅指训练得到的类别专家。

### 2.2 关键技术组件

- **可执行 SWE 任务构建**：从合并的 PR 与关联 issue 构建，包含 base revision、issue 式问题陈述、环境规格与可执行测试；分离 fix patch 与 test patch；LLM 改写问题陈述并做泄漏检查、去重与污染审计；环境构建遵循 RepoLaunch，通过 gold patch 前后测试验证，过滤 flaky verifier；候选池约 32K。

- **SWE Labeler（基于证据的多轴标注系统）**：
  - 两个语义轴：**Task Type**（26 个 L1 / 119 个 L2）与 **Repository Domain**（21 个 L1 / 108 个 L2）；
  - 三个正交尺度轴：修改范围、认知复杂度、预估解决时间，各 4 级，共 12 级；
  - 标签契约：每个标签记录权威来源 `aℓ`、来源概念 `d^src`、操作规则 `d^op`、可观测正信号 `s+`、与邻近标签的边界 `bℓ`；
  - 来源包括 ISO/IEC 25010、ISO/IEC/IEEE 14764、MITRE CWE、Fowler 重构目录、NIST 数字身份指南等；
  - 两阶段标注：先预测 L1，再在 L1 子节点中选 L2；支持 issue–change 实例与交互轨迹两种输入适配器。

- **路由类别构造**：以 Repository Domain L1 为路由轴，将 18 个可路由 L1 粗化为三条工程语境：
  - **A**（service/data/security）：web_backend、database_storage、data_engineering、data_science、cms_ecommerce、security_auth、blockchain_web3；
  - **B**（user-facing applications）：web_frontend、desktop_gui、mobile_dev、media_graphics、game_dev；
  - **C**（systems/tooling/runtimes）：devops_infra、devtools_test、pkg_manager_cli、os_system、iot_embedded、lang_runtime；
  - 映射为确定性、互斥规则 `c(x)=g_ψ(z^domain_L1(x))∈{A,B,C,∅}`。

- **Agentic-miniRL**（长时程多轮 SWE 轨迹的 RL 配方）：
  - **RLOO 奖励中心化**：`R̄_i = R_i − (1/(G−1))Σ_{j≠i}R_j`，等价于 `G/(G−1)` 倍的均值中心化 GRPO 优势；对 G=8 的单成功组，成功轨迹优势为 1（含自身均值中心化为 7/8），避免进一步衰减稀疏成功信号；
  - **K1 正则置于 return-to-go 之前**：`er_{i,t}=1[t=T_i]R̄_i−β·d^K1_{i,t}`，再反向折扣累积为 token 级优势；K1 作为 stop-gradient 奖励比 K3 作辅助损失有更正确的梯度；
  - **MiniRL token 更新**：用有界重要性权重 `w_{i,t}=clip(π_θ/μ_b, c_min, c_max)` 纠正 rollout 与训练器的行为概率失配，并施加符号感知的 proximal mask `M_{i,t}`，仅在策略朝优势方向越过边界后抑制该 token 更新；
  - **Turn-aware reduction**：`seq-mean-segment-sum`——在每个 assistant turn 内对 token 求和，在轨迹内对 turn 求平均，再在有效轨迹上求平均；工具观测 token 被 response mask 排除。

- **Refresh–Repair–Expand（RRE）类别专家训练**（每类独立实例化）：
  - **Refresh（刷新）**：RL 后用 π_RL 在训练集上重新评估掌握度 `p̂_RL`，与进入该阶段前的 `p̂_pre` 配对得到 Δ，定位回退实例；SFT 后再刷新一次；
  - **Repair（修复）**：仅回放该专家在本 RL 阶段生成的、验证器认可的成功轨迹 `B^(r)_c(x)`；配额 `q^(r)_c(x)=g_rep(p̂_RL(x))` 非增，低掌握度实例获得更多不同成功轨迹；SFT 损失只对 assistant token 计算；
  - **Expand（扩展）**：下一轮 RL 前，在候选池中随机加入 base 通过率为 0 或 1 的实例形成 U，用 post-SFT 策略评估得到 `p̂_pre`；下一轮 RL 集为当前信息前沿 `F={0<p̂_pre<1}` 与历史有成功证据的可恢复零实例 `Z={p̂_pre=0∧H=1}` 的并集；纯硬零与当前饱和实例被排除。

- **标签路由多教师同策略蒸馏（MOPD）**：
  - 学生从原始基座 π_0 初始化，在类别均衡混合（A/B 上采样至 C 的 1,652 条，共 4,956 条）上训练；
  - 学生自行生成完整轨迹，教师只被查询学生实际访问的前缀（on-policy）；
  - 定义两个对数比：学生–教师差距 `d_{t,k}=q_t−log π_{T_k}` 与教师–参考差距 `e_{t,k}=log π_{T_k}−log π_ref`；
  - **路由多教师优势**：`A^MOPD_t = Σ_k m_k(x)[−d_{t,k} + (λ_k−1)·max(e_{t,k},0)]`；
  - 当 λ_k=1 时退化为标准 MOPD 模仿项；λ_k>1 时在教师比参考更倾向的 token 上做参考锚定的奖励外推；
  - **ReLU 门控**：`ẽ_{t,k}=max(e_{t,k},0)`，仅保留教师–参考正对数概率差，避免正负贡献相互抵消、使外推项获得系统方向；配置 λ_k=1.25，ReLU 门控开启；
  - 纯蒸馏模式：每个任务一次 rollout，环境回报不进入学生损失，group baseline 与 K1 参考惩罚禁用，π_ref 仅作外推锚点；
  - 学生目标复用 turn-aware reduction，路由优势作为 per-token 权重，优势裁剪至 `[−5,5]`，采用 vanilla policy gradient（无 proximal mask 与重要性比纠正）。
