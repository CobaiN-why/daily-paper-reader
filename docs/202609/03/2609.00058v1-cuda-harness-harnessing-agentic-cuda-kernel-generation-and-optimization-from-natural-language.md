## 摘要
开发高性能CUDA内核需要算法实现、正确性验证和硬件感知的并行优化等方面的专业知识，这构成了巨大的专业壁垒，使得直接从自然语言生成CUDA内核（Text2CUDA）变得至关重要。与此同时，大语言模型（LLM）的通用代码生成能力催生了一系列探索基于LLM的CUDA内核生成的工作。这些工作主要侧重于从高级框架（如PyTorch）到CUDA的转译（Torch2CUDA），而非Text2CUDA——在Text2CUDA中，模型必须理解高级输入语义，并处理底层内核实现与验证。此外，由于依赖预定义的测试输入，这些方法容易遭受奖励黑客攻击。在本文中，我们提出CUDA-Harness，一个利用智能体从自然语言生成并优化CUDA内核的框架。具体而言，我们引入中间结构生成，将高级语义理解与底层内核生成相连接。为稀释Text2CUDA中的奖励黑客问题，我们构建基于综合的验证，提供隔离的测试数据和渐进式验证。此外，我们提出反馈自适应进化，一种优先考虑正确性同时优化性能的内核进化策略。最后，通过大量实验，我们证明了CUDA-Harness的有效性，进一步评估展示了其在多种LLM、硬件平台以及C到CUDA转译任务上的泛化能力。

## Abstract
Developing high-performance CUDA kernels demands specialized knowledge in algorithm implementation, correctness validation, and hardware-aware parallel optimization, creating a substantial expertise barrier and making generating CUDA kernels directly from natural language (Text2CUDA) essential. Meanwhile, the general-purpose code generation capability of Large Language Models (LLMs) prompts a series of works exploring LLM-based CUDA kernel generation. They mainly focus on transpilation from high-level frameworks such as PyTorch to CUDA (Torch2CUDA) rather than Text2CUDA, where models must understand the high-level input semantics and handle low-level kernel implementation and validation. Additionally, these methods are vulnerable to reward hacking due to reliance on predefined test inputs. In this paper, we propose CUDA-Harness, a framework for harnessing agentic CUDA kernel generation and optimization from natural language. Specifically, we introduce Intermediate-Structured Generation to connect high-level semantic understanding with low-level kernel generation. To dilute reward hacking in Text2CUDA, we construct Synthesis-Based Verification to provide isolated test data and progressive validation. Furthermore, we propose Feedback-Adaptive Evolution, a kernel evolution strategy that prioritizes correctness while optimizing performance. Finally, through extensive experiments, we demonstrate the effectiveness of CUDA-Harness, with further evaluations illustrating generalization across LLMs, hardware platforms, and to C-to-CUDA transpilation.

### 1. 核心问题与整体含义（研究动机与背景）

- 开发高性能CUDA内核需要同时具备算法实现、正确性验证、硬件架构理解与并行优化等多方面的专业知识，技术门槛高，**严重限制了GPU编程的可及性**。
- 大语言模型（LLM）的代码生成能力使得**直接从自然语言生成CUDA内核（Text2CUDA）** 成为可能，但现有工作存在两个突出问题：
  1. **任务偏移**：多数研究聚焦于PyTorch等高层框架到CUDA的转译（Torch2CUDA），这类任务算法语义已被代码显式定义，并非真正的Text2CUDA。Text2CUDA需要模型同时处理高层语义理解（输入可能不完整、含糊）与底层内核实现、验证，难度更高。
  2. **奖励黑客（Reward Hacking）风险**：现有智能体方法普遍依赖预定义测试输入进行验证和反馈，模型容易过度拟合特定测试数据，优化建立在有缺陷实现之上。
- 论文提出**CUDA-Harness**框架，旨在系统性地解决Text2CUDA中语义理解、测试数据缺失和可靠性验证三大挑战，让自然语言成为编写正确且高效CUDA内核的可行接口。

### 2. 方法论：核心思想与关键技术细节

CUDA-Harness包含三个核心组件，对应解决“语义理解—验证—优化”的完整闭环。

#### 2.1 组件一：中间结构生成（Intermediate-Structured Generation, ISG）

- **目的**：弥合高层语义理解与底层内核实现之间的鸿沟。
- **内核实现清单（Kernel Implementation Manifest）**：将用户模糊的自然语言输入转化为**结构化的逐内核规格说明**。每个条目记录内核名称、输入输出描述、功能描述（揭示算法细节）、语言无关的参考代码片段，以及详细的测试信息（形状、数据类型等）。生成清单时，智能体专注于语义理解和补全缺失细节，而不直接写内核代码。
- **自包含CUDA脚手架（Self-Contained CUDA Scaffold）**：一个代码模板，包含头文件、内核与启动器占位符，以及处理二进制文件读写、参数检查、内核调用的`main`函数。它：
  - 将内存管理、数据传输、启动配置等聚合到独立的启动器（launcher）中，让智能体聚焦于内核本身；
  - **禁止使用dummy输入**，测试输入路径通过命令行参数传入，调用约定在编译时通过`#pragma message`输出，从而使智能体在实现内核时无法得知测试数据细节，从源头削弱奖励黑客风险。

#### 2.2 组件二：基于综合的验证（Synthesis-Based Verification, SBV）

- **目的**：解决Text2CUDA中测试数据不可得的问题，提供可信的正确性信号。
- **解耦的测试数据合成（Decoupled Test Data Synthesis）**：
  - 测试输入与参考输出通过标准数值库（NumPy/PyTorch）在**隔离环境**中生成，与内核生成的上下文完全隔离，避免交叉污染；
  - 要求测试输入覆盖**广泛的数值范围**（如均值为5.0、标准差为10.0的高斯分布），防止小幅度输入导致数值容差判据（`ϵ_rtol|y|`）失效，从而放过数值不正确的内核；
  - 尽管大数值输入可能放大浮点累积误差、增加假阴性，论文认为“拒绝正确内核”比“接受错误内核”更可接受，因为后者会误导后续优化。
- **渐进式多阶段验证（Progressive Multi-Stage Validation）**：遵循**快速失败（fail-fast）** 顺序，先检查编译（公式`C(K; φ)`），再检查功能正确性（公式`V(K, x, y)`），最后测量运行时性能（公式`P(K, x)`）。验证工具基于模型上下文协议（MCP）封装提供统一接口，支持硬件可扩展验证。

#### 2.3 组件三：反馈自适应进化（Feedback-Adaptive Evolution, FAE）

- **目的**：在内核优化过程中优先保证正确性，避免错误累积。
- **正确性优先的修正（Correctness-First Refinement）**：根据验证失败的阶段分支处理：
  - 编译失败 → 基于编译错误细节进行针对性修复；
  - 功能验证失败 → 指示智能体退回更保守的实现，以正确性为第一优先级。
  - 该机制防止智能体在功能有缺陷的“高性能”实现基础上继续叠加激进优化，避免陷入错误的优化路径。
- **奖励驱动的优化（Reward-Driven Optimization）**：
  - 采用带可验证奖励的强化学习（RLVR）驱动，奖励信号定义清晰：`r(K) = −1 + C(K) + C(K)·V(K)·P(K)`（编译失败受罚，通过功能验证后按性能打分）；
  - 引入**优化洞察摘要**机制：智能体分析内核改动与奖励变化的差异，提炼有效/无效的优化策略经验（公式`e = Me(Diff(K_post, K_pre), Δr)`），并在多轮迭代中累积利用这些经验指导后续优化（目标函数`J(Ei)`）。
